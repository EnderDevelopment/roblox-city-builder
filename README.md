# Roblox City Project

This project is a Roblox city builder that allows players to create and interact with a virtual city. The project includes scripts for creating houses, managing player interactions, and implementing a day-night cycle. The city is built on a terrain that can be customized with various materials and colors.

## Install

1. Open Roblox Studio.
2. Import the Terrain.rbxm file into the Workspace.
3. Import the House.rbxm file into the Workspace.
4. Place the scripts in the appropriate locations as described below:
   - Place the HouseScript.server.lua script inside the House model in the Workspace.
   - Place the PlayerInteraction.server.lua script in ServerScriptService.
   - Place the DayNightCycle.server.lua script in ServerScriptService.

## Use

1. Run the game in Roblox Studio.
2. The city terrain will be created automatically.
3. Use the HouseScript to create houses at specific positions in the city.
4. Players can join the game and interact with the city environment.
5. The day-night cycle will automatically update the lighting and sky color based on the in-game time.
